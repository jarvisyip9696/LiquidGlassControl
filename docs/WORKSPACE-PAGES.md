# 四页工作区 UI 重构

新增 `src/workspace_pages.h`，由现有 Direct2D / DirectWrite 绘制器调用。坐标沿用全窗口 1280 × 900 设计，内部统一扣除设计标题栏 52 DIP，再按实际原生客户区原点补偿。

- 系统玻璃：八条 54 DIP 设置行；通知中心与日历合并控制原有两个后端开关。
- 材质：三根 560 DIP 滑杆，范围读取已有 trackbar，不按示意滑块坐标反推最大值；松开通过既有 WM_HSCROLL 保存对应区域配置。保留紧凑的作用范围入口，Dock 独立参数仍通过高级界面使用。
- LGEngine：四个下拉选择、重播、示例指示器；后台开关协调既有音量与亮度两项开关。已保存状态保留，未强制覆盖成设计截图的开启状态。
- 设置：常规/关于、语言、White/Dark、启动淡入、托盘说明和真实预览连接状态。
- White/Dark 共享几何与键盘/鼠标路径。自绘控件使用原有隐藏原生控件的数据与命令处理；原有高级界面可由窗口系统菜单切换进入。
- 系统材质、托盘和配置后端沿用。右侧材质图为静态示意，不代表第三方应用内容区透明，不模拟实时系统变化。

视觉边界：保留 Windows 原生标题栏及系统控制的外圆角。Dark 关于图标由原生圆角形状近似绘制；LGEngine 右侧使用静态指示器示意。界面不宣称像素级一致。

显示版本按设计为 v0.12.0-beta.4；底层源代码仍为当前项目 v0.13.3。
