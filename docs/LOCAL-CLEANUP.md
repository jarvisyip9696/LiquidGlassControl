# 本地清理与构建缓存

2026-10-17 的目录体积主要来自 `build`（约 197 MiB），源码 `src` 约 0.3 MiB。已清除重复候选版本、过期中间文件以及停用的任务栏高光实验实现，保留独立 LGEngine 预览和旧设置恢复代码。

生成头文件按当前编译器预处理依赖清单精简，保留实际引用文件，再压缩到 `build/winrt/headers.zip`。`build.ps1` 在需要时自动解压；成功构建后删除本次临时展开的头文件和重复 `.o` / `.res`，保留二进制和缓存。CMake 在缺少头文件时也可展开该缓存，但为支持增量构建，不会自动删除 CMake 使用的头文件。

新增 WinRT API 后若需要其他生成头文件，可重新运行 `prepare-winrt.ps1`。CI 从源代码准备完整依赖，不依赖这份本地精简缓存。发行包不包含开发缓存。

旧目录中的个人 INI 和恢复记录复制到 `build/preserved-state`，原始位置的必要记录也保留。旧设置迁移、属性恢复、测试和第三方许可证仍然使用，不应视为无用代码删除。Git 历史保留。

少量旧引擎 DLL 仍由 Explorer/系统面板映射，无法立即删除。这些剩余文件没有通过终止 Explorer、修改安全策略或强行卸载清理；可在系统自然释放后移除对应的旧候选目录。保留的最新已验证版本为 `build/candidates/glass-defaults-fix`，清理后的开发构建为 `build/candidates/clean-current`。
