# Liquid Glass Control 0.12.0-beta.3

基于 beta.2 的后台资源优化，保留原有玻璃效果、键盘面板和恢复行为。

- 所有效果关闭时按需加载引擎，不启动每秒引擎定时器；启用效果后恢复正常心跳。
- 隐藏到托盘时释放应用列表和复制的图标，重新打开时重建。
- 状态轮询不再重复发送未变化的成功/失败消息，保留状态转换、错误变化和重新连接回执。

本机一次隔离对比：托盘冷启动、所有效果关闭，平均私有内存从 **3.30 MiB → 2.58 MiB（约 -22%）**；工作集 **18.66 MiB → 15.68 MiB（约 -16%）**。这是本地构建的特定场景采样，不代表所有设置、系统宿主或 CI 发布二进制都有同样降幅。方法与限制见仓库 `docs/POWER-MEMORY.md`。

已减少关闭效果时的周期唤醒；没有测量实际瓦数或硬件能耗，不宣称功耗降低百分比。

验证：新增缓存与状态转换回归，以及原有引擎加载、COM、Composition、配置、滑块重置、五语言/DPI 和恢复自测通过。发行包另由 GitHub Windows CI 构建、自测和打包。

Windows 11 x64，仍为未签名实验版。下载 EXE 或便携 ZIP，无需 Windhawk。
