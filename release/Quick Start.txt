Liquid Glass Control 0.14.0 - Performance Refresh
Windows 11 x64 - Portable release

1. Extract the complete ZIP to a writable folder and run LiquidGlassControl.exe.
   Keep art/, fonts/, and lgengine/ beside the controller.
2. System glass > Effects controls the supported shell surfaces and Dock.
   File Explorer styling is no longer included.
3. System glass > Materials adjusts blur, tint, corners, and power saving.
4. System glass > LGEngine configures entrance styles, indicator entrance,
   slosh, knob style, replay, and the sample indicator.
5. Enabled volume and brightness indicators continue to work on other pages
   and in the tray. The sample does not change system volume or brightness.
6. Settings changes the interface language and appearance. Settings save
   automatically. Use the tray menu to restore managed effects and exit.
7. Create Desktop Shortcut.cmd can create an optional desktop shortcut.

Windows toast notifications and the native volume flyout are not replaced.
Brightness integration depends on hardware support. Windhawk is not required.
The LGEngine host uses the Windows-provided .NET Framework runtime.

This build is unsigned and may be blocked by Windows application control.
Use a trusted, approved build; do not disable security protections.
Keep your settings and recovery records until restoration succeeds.
