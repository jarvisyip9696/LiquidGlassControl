# Liquid Glass Control 0.12.0-beta.2

- 新增键盘布局切换面板玻璃开关。改用桌面背景采样并清除遮挡底色，保留语言选择和高亮；本机用户已确认玻璃效果显示正常。
- 设置中的“恢复默认参数”只重置着色、模糊、圆角三个滑块为 **35 / 12 / 12**，保留效果开关、色调和省电选择。
- “跟随系统”读取 Windows 系统主题选项。
- 包含系统材质连接、通知宿主恢复和任务栏/Dock 修正。
- 移除导致重复胶囊的任务栏光学高光实验及其构建路径。LGEngine 独立预览适配仅供本地构建，不随发行包分发。
- 清理重复开发产物；本地生成头文件可使用压缩缓存，构建成功后自动收回临时展开目录和中间资源文件。

验证：原生引擎加载、COM、Composition、配置连接、滑块重置、恢复夹具及五语言/DPI 自测；翻译覆盖检查。发行包从隔离目录运行自测，并附完整对应源码、许可声明和 SHA256 校验值。

仍为未签名实验版。不同 Windows 构建、多显示器、通知中心/日历各界面的最终外观和完整恢复仍需进一步验证；没有宣称性能、功耗或内存降幅已测量。完整光学折射与色散未实现。

Windows 11 x64。下载 EXE 或便携 ZIP；无需安装 Windhawk。
