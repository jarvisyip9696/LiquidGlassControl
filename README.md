# Liquid Glass Control

轻量 Windows 11 玻璃效果工具 · Windows 11 x64

**[下载 EXE](https://github.com/jarvisyip9696/LiquidGlassControl/releases/download/v0.12.0-beta.3/LiquidGlassControl-0.12.0-beta.3-win11-x64.exe) · [下载便携 ZIP](https://github.com/jarvisyip9696/LiquidGlassControl/releases/download/v0.12.0-beta.3/LiquidGlassControl-0.12.0-beta.3-win11-x64.zip) · [发布说明](https://github.com/jarvisyip9696/LiquidGlassControl/releases/tag/v0.12.0-beta.3) · [全部版本](https://github.com/jarvisyip9696/LiquidGlassControl/releases)**

- 系统玻璃效果（含键盘布局切换面板、任务栏胶囊外观）和 Dock 悬停动画。
- 可调模糊、着色和圆角，一键重置三个滑块，支持五种语言与设置保存。
- 无需 Windhawk；关闭至托盘，可还原并退出。
- 后台按需加载、图标缓存释放；[内存对比与节能说明](docs/POWER-MEMORY.md)。

当前版本：**0.12.0-beta.3**。下载仅包含发布文件，不包含开发缓存或个人设置。

开发中：[LGEngine 光学预览适配](integrations/LGEngine/README.md)，可本地构建体验折射、色散和边缘光。当前未替换系统界面引擎，未加入发布包。造成重复胶囊的任务栏高光实验已移除。

> 实验版，当前未签名。通知中心效果尚未确认；胶囊托盘、弹出菜单及完整恢复仍需实测。实际功耗、开启效果时的内存尚未测量；托盘关闭效果时的应用内存对比见优化说明。

Lightweight glass controls for Windows 11 x64, with adjustable blur, tint and corners, five languages, a capsule appearance built into the taskbar switch, and Dock hover animation. No Windhawk runtime required. Close to tray; restore and exit to revert effects.

Experimental, unsigned build. Notification styling is unconfirmed; capsule tray appearance, popups and complete restoration need live testing. Effects-off tray memory was sampled locally; active-effect memory and hardware energy savings have not been benchmarked.
